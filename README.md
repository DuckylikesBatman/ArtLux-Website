# ArtLux-Website

## Overview
ArtLux is the website for a Beirut decorative-painting and fine-art studio: bespoke murals, gold leaf and arabesque wall/ceiling finishes, furniture restoration, and original paintings.

## Features
- **Projects**: Filterable portfolio of completed interiors (residential, healthcare, furniture restoration) with a detail modal per project.
- **Gallery**: Masonry layout of original paintings and fine art.
- **Commission**: Multi-step request form (artwork type, dimensions, details, photo upload) submitting via Formspree.
- **About**: The studio's story, founder, stats, and services.
- **Contact**: Contact form (Formspree) plus an embedded map.
- **EN/AR language toggle**: Fully bilingual site (nav, footer, and all page content) via `lang.js`.

## Tech Stack
- **HTML**: Utilized for creating structured web pages.
- **CSS**: Applied for styling and layout enhancements to provide a polished look and feel.
