# ArtLux-Website

## Overview
ArtLux is an art portfolio and e-commerce website designed to showcase artwork and facilitate online sales through a user-friendly interface.

## Features
- **Gallery**: Display various artworks in a visually appealing layout.
- **Commissions**: Information on how to commission custom artwork.
- **About**: Learn more about the artist and the inspiration behind the work.
- **Contact**: Easy ways to get in touch for inquiries.
- **Checkout**: Seamless online purchasing experience for artworks.

## Tech Stack
- **HTML**: Utilized for creating structured web pages.
- **CSS**: Applied for styling and layout enhancements to provide a polished look and feel.
